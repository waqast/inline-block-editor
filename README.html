Inline Block Editor (IBE)

A portable, framework-agnostic, block-based inline HTML editor built with native HTML5 contenteditable, ES6+ JavaScript, and CSS custom properties.

v1.0.0 — Completely Portable. Bundled as a Universal Module Definition (UMD) component with built-in paste sanitization, keyboard shortcuts, event system, and CSS custom property theming.

Key Features

Designed to be lightweight, easy to integrate, and fully customizable to fit your CMS or web workspace.

Block Architecture

Create paragraphs, headings, images, videos, alerts, lists, tables, code blocks, raw HTML, and dividers seamlessly.

Drag-and-Drop

Rearrange blocks smoothly with SortableJS integration. Supports fluid draggable mechanics with animated ghost states.

Floating Toolbars

Context-sensitive toolbars adapt to each block type — text formatting, image settings, video embeds, table controls, and more.

CSS-Isolated

All styles prefixed with .ibe-, keeping your global CSS safe. Full theming via CSS custom properties.

Paste Safe

Built-in paste sanitizer strips dangerous HTML (scripts, iframes, event handlers). Customize with the onPaste callback.

Event System

Subscribe to change, save, block:add, block:delete, block:move, and mode:change events.

Keyboard Shortcuts

Ctrl+S to save, Escape to exit edit mode. Native Ctrl+B/I/U formatting supported.

Multi-Instance

Run multiple independent editor instances on the same page without interference. Each has its own scoped state.

Installation & Setup

Embed the stylesheet, JavaScript core file, and required icon/sorting libraries into your workspace header.

1. Local Library Assets

Link the isolated editor styling sheets and JS scripts from your project folder:

HTML<!-- Editor Stylesheet -->
<link rel="stylesheet" href="lib/inline-block-editor/inline-block-editor.css">

<!-- Editor Core Script -->
<script src="lib/inline-block-editor/inline-block-editor.js"></script>

2. External Libraries (CDN)

Incorporate the vector icons package, draggable sorting engine, and code highlight stylesheets:

HTML<!-- Lucide Icons (Required for toolbars) -->
<script src="https://unpkg.com/lucide@latest"></script>

<!-- SortableJS (Optional - for drag-and-drop block sorting) -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/Sortable/1.15.0/Sortable.min.js"></script>

<!-- Highlight.js (Optional - for code block syntax styling) -->
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/highlight.js/11.8.0/styles/github-dark.min.css">
<script src="https://cdnjs.cloudflare.com/ajax/libs/highlight.js/11.8.0/highlight.min.js"></script>

Only Lucide is required. SortableJS enables drag-and-drop; Highlight.js enables syntax highlighting in code blocks. Both degrade gracefully if absent.

Getting Started

To launch the editor, place a target layout element in your HTML and instantiate the library with your custom options.

1. Define the HTML Container

HTML<div id="editor-container">
    <!-- Initial content will be migrated into block format automatically -->
    <h2>Welcome to the Inline Block Editor</h2>
    <p>Click anywhere in this paragraph to edit its text inline.</p>
</div>

2. Initialize the Editor

JavaScriptconst editor = new InlineBlockEditor('#editor-container', {
    onSave: async (html, metadata) => {
        const response = await fetch('/api/save', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ html, id: metadata.pageId })
        });
        return (await response.json()).success;
    },

    onUpload: async (file) => {
        const formData = new FormData();
        formData.append('image', file);
        const res = await fetch('/api/upload', { method: 'POST', body: formData });
        return (await res.json()).url;
    },

    isDirtyChange: (dirty) => {
        console.log(dirty ? 'Unsaved changes!' : 'Clean.');
    }
});

Options API Reference

Customize the editor setup using the following config attributes:

Option Type Default Description
endpoint String "" The URL for standard POST form submissions if onSave is not defined.
onSave Function null Async save handler callback: async (html, metadata) => Boolean
onUpload Function null Async upload handler callback: async (file) => String (Return public URL)
onImageZoom Function null Image zoom callback: (src, alt, images) => void
onPaste Function null Custom paste processor: (html, plainText) => sanitizedHtml
confirm Function null Async confirm dialog callback: async (title, msg, btnText, type) => Boolean
allowedBlocks Array ['p', 'image', 'video', ...] Enabled block types in the insertion menu.
isDirtyChange Function null Callback fired when the unsaved changes state changes: (isDirty) => void
debug Boolean false Enable debug logging to console.

Methods API

Interact programmatically with the active editor instance using these class methods:

getContent() / getHTML()

Returns clean HTML output with all editor artifacts removed.

JavaScriptconst htmlOutput = editor.getContent();

setHTML(html)

Replaces editor content with new HTML and re-initializes all blocks.

JavaScripteditor.setHTML('<p>New content loaded.</p>');

save(metadata = {})

Triggers the save pipeline, calling onSave or posting to endpoint.

JavaScriptawait editor.save({ articleId: 45 });

setPreviewMode(preview) / enable() / disable()

Enables or disables edit controls globally. Useful for toggling draft mockups vs. static previews.

JavaScripteditor.setPreviewMode(true);  // Preview mode
editor.enable();               // Edit mode
editor.disable();              // Preview mode

isEnabled()

Returns true if the editor is in edit mode.

JavaScriptif (editor.isEnabled()) { /* editing */ }

clear()

Removes all blocks and creates a single empty paragraph.

JavaScripteditor.clear();

duplicateBlock(block)

Duplicates the given block element and inserts it directly below, complete with regenerated IDs and initialized controls.

JavaScriptconst block = container.querySelector('.ibe-block');
editor.duplicateBlock(block);

destroy()

Unbinds all event listeners, destroys Sortable, removes editor UI, and cleans up. Safe to call multiple times.

JavaScripteditor.destroy();

showToast(message)

Displays a brief toast notification at the bottom-right of the screen.

JavaScripteditor.showToast('Changes saved!');

Events

Register event listeners with on() and remove with off():

JavaScripteditor.on('change', () => console.log('Content changed'));
editor.on('save', (data) => console.log('Saved:', data.success));
editor.on('block:add', (data) => console.log('Added:', data.type));
editor.on('block:delete', (data) => console.log('Deleted:', data.type));
editor.on('block:move', () => console.log('Block reordered'));
editor.on('mode:change', (data) => console.log('Preview:', data.preview));

Block Reference

Below is the structured markup format generated by each editor block option:

Standard Block Wrapper

Every block is structured like this:

HTML<div class="ibe-block col-12" data-type="p">
    <div class="ibe-block-content">
        <p>Paragraph text content...</p>
    </div>
</div>

Available Block Types (data-type)

  • p: Standard paragraph text.
  • h2 / h3: Document headings.
  • ul / ol: Unordered and ordered lists.
  • image: <figure> block with <img>, optional <figcaption>, link wrapping, and aspect ratio setting (.aspect-original).
  • video: Responsive iframe container (YouTube/Vimeo) with optional <figcaption>.
  • alert: Alert boxes (.alert-box.info, .success, .warning, .danger).
  • code: Code block with syntax highlighting and language selector.
  • table: Table with bordered/striped styling, add/remove rows and columns.
  • html: Raw HTML block with toggle between edit and rendered view.
  • hr: Divider block. Supports styles (.ibe-hr-solid, .ibe-hr-dashed, .ibe-hr-dotted, .ibe-hr-double) and widths (.ibe-hr-full, .ibe-hr-medium, .ibe-hr-short).

Security

  • Paste sanitization: All pasted HTML is stripped of <script>, <iframe>, <style>, <object>, <embed>, <form>, and event handler attributes.
  • Template escaping: All user-provided values interpolated into modal HTML are escaped to prevent XSS via _escAttr().
  • Custom paste handler: Use the onPaste option for full control over paste processing.
